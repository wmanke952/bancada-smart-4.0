# Bancada Smart 4.0

Projeto de desenvolvimento e modernização do sistema da **Bancada Smart 4.0**.

## Objetivo

Desenvolver uma aplicação para gerenciamento, operação e acompanhamento das Bancadas Smart 4.0.

## Estrutura do projeto

```text
bancada-smart-4.0/
├── backend/
├── frontend/
├── docs/
└── README.md
```

### Backend

Responsável pela API, regras de negócio, persistência de dados e integrações.

### Frontend

Responsável pela interface da aplicação e comunicação com a API.

### Documentação

A pasta `docs/` será utilizada para armazenar os documentos produzidos durante as diferentes fases do projeto.
